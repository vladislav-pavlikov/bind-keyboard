bind-keyboard

npm ↗ GitLab ↗

A lightweight (~5KB gzip), dependency-free library for binding keyboard shortcuts — layout-agnostic, cross-platform, and safe by default.

Press any key combination to see it detected below.

This demo reacts to real keydown/keyup events — best experienced with a physical keyboard.

Detected combination —
keyMode

key matches event.key (layout-aware — e.g. Ctrl+A needs an actual "A" from the active layout); code matches event.code, the physical key position, regardless of layout.

Layout (visual only)

When checked, shortcuts are suppressed while the input below (or any text field/textarea/select/contenteditable) is focused — except bindings marked allowInInputElements, like Escape.

Registered shortcuts press ? for full view

    Features

    • ⌨️ Bind callbacks to key combinations, including multiple per callback
    • 🌐 Layout-agnostic matching via event.code — no need to switch to a Latin layout
    • ⌘ cmdOrCtrl — one binding, the right modifier on every platform
    • 🛡️ Input-safe by default — shortcuts skip text fields, with a per-binding override
    • 🪶 ~5KB gzipped, zero dependencies
    • 🖥️ SSR-safe — skips autostart instead of throwing when there's no DOM yet
