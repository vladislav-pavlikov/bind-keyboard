# Security Policy

## Supported versions

`bind-keyboard` is a single small package with no runtime dependencies. Only the latest version published on [npm](https://www.npmjs.com/package/bind-keyboard) receives fixes — there's no maintained branch for older major versions.

## Reporting a vulnerability

Please **don't** open a public GitHub issue for a security vulnerability.

Instead, use GitHub's private vulnerability reporting for this repo:
**[Report a vulnerability](https://github.com/vladislav-pavlikov/bind-keyboard/security/advisories/new)**

This opens a private draft advisory visible only to the maintainer, so the issue isn't public before a fix ships.

Include what you'd include in any report: the affected version, a description of the issue, and steps to reproduce (a minimal repro is ideal).

## Response

This is a solo-maintained project — there's no formal SLA, but reports are triaged as soon as reasonably possible, and a fix is prioritized once confirmed.
